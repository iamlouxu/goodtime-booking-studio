# 留白 Blank Studio

可同步的獨立工作室預約 MVP，支援繁體中文、RWD、店家專屬預約頁與 Instagram 4:5 月曆圖。

## 使用

1. 在首頁透過 ChatGPT 登入並建立工作室。
2. 月曆選日期，新增開始時間（如 10:00, 14:00），再複製專屬預約連結。
3. 客人免登入送出預約，時段立即變成待確認；老闆接受或婉拒。
4. 空檔製圖會排除待確認、已預約、關閉及過期時段，可上傳背景照片並下載 1080×1350 PNG。

## 資料與權限

Cloudflare D1 持久保存店家與時段。每個 Sites ChatGPT 使用者擁有一間獨立工作室，所有管理操作在伺服器驗證 owner。匿名回應不含客人姓名、電話、備註或預約識別碼。預約以單一條件 UPDATE 保留時段，避免同時預約兩次。以台北時間判斷過期，畫面每 5 秒重新讀取。

## 已知範圍

單人工作室、單一時間一位客人；不計算服務時長、不寄送通知、不收款。接受、婉拒或取消後，由店家自行聯繫客人。待確認時段不自動到期。背景照片只在本次瀏覽器記憶體使用，不上傳與跨裝置同步。正式使用前可加入反濫用限制、顧客查詢及通知機制。

## 開發

保留 Sites / Vinext starter 及登入整合。npm run dev 啟動 loopback 預覽；npm run db:generate 產生 schema migration。透過 Sites build-site.mjs 建置及 site-workflow.mjs 封裝發布。測試資料僅存在本機，不會隨部署搬至正式 D1。

## 已驗證

TypeScript、正式建置、匿名管理拒絕、跨店預約拒絕、重複時間去重、同時預約僅一筆成功、公開資料不含聯絡資訊、確認狀態轉移、關閉與重新開放、過期時間驗證。瀏覽器完成客人表單送出、桌面／手機預覽及 PNG 尺寸確認。
